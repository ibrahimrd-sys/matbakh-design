Check every frame

The rules a page must obey

Structure

  • One step = one page = one station. If the cook has to move, that is a new page — even for a single action.
  • Several actions on a page only if order-independent and one station. All the knife prep is one page. Sear and deglaze are two — in cooking the sequence is the information.
  • Waiting is never a page. A timer attached to the preceding action.
  • 6–10 pages typical, 14 hard ceiling. Over it is an editorial signal, not a formatting problem.
  • Nothing scrolls.

The two tests while drawing

  • Granularity: a step ends when you next need to look at the screen. Hands, not grammar.
  • The metric is pages you must re-read, not page count. Turning a page is nearly free; reconstructing which half you had done is not.

Three carriers

  • Icons — actions
  • Digits + units — quantity
  • Words — only the name of the thing, and irreducible judgement

What a frame accounts for

Anatomy of one page

The step — one page

  • station — closed list of six: board stove bench grill oven serve
  • qualifier — renders “Stove · takliya”. How four stove pages stay distinct
  • ordered — only if out-of-sequence ruins the dish. Default false; meaningless on a single tile
  • heat — 1 low · 2 medium · 3 high
  • timer {minutes, label, mass_sensitive} — belongs to the session, not the page
  • makes — names an intermediate
  • photo + doneness — travel together, always
  • note {kind, text} — four kinds only

The tile — one action

  • do (lexicon key — the verb comes free in 5 locales) or verb + glyph (bespoke, the escape hatch)
  • qualifier · item / items[] · amt
  • carried: true — same physical ingredient reappearing later, so the basket counts one bird not three
  • cut + cut_mm — the cut is a result; cut_mm carries what a glyph cannot
  • into — data, never a caption. It briefs the picture; it does not print
  • short — attaches a technique clip
Glyph resolution: tile.glyph → activity.glyph → ingredient.glyph. The activity glyph wins over the ingredient glyph — the builder had this inverted until 19 August. Ingredient glyphs are coarse categories: 45 ingredients share jar, 38 share vegetable, so a page of four spices drew four identical pictures.

Coverage, not convenience

The smallest set that stresses imagery

The pilot's fifteen were chosen for coverage. Storyboarding is far cheaper than cooking, so do more if you can — but if you want the minimum that pressures this decision, it is six, of which two already exist.

Per page: station · tile count · ordered · timer · has doneness · would you re-read this page.  Per recipe: page count against 6–10/14 · activities used · bespoke count · demotions · sub-recipes · minutes to draw it.

Thresholds — after the batch, never during

  • Add a verb only if reached for in ≥3 recipes
  • Promote a demotion back if it read awkwardly in ≥2
  • Split an icon if a glyph failed at 17 px anywhere, or two actions collided in practice
  • Fix an Arabic cell if a drafted verb felt wrong in even one context
  • An unexercised activity means examine, not delete

Exit criteria — all four must hold

  • ≥90% of actions mapped to an activity or a clean activity + qualifier
  • No new verb recurred ≥3× without being addressed
  • Every icon read at both 44 px and 17 px, no unresolved collision
  • Every drafted-Arabic verb that appeared was confirmed or corrected
Learned the hard way

Traps

  • The 20 SVGs in design/icons/ are geometric placeholders, not the production Tabler set, and several of the 81 glyph names are invented. The prototypes render them at full fidelity, so they read as finished. They are not — C-05 is open.
  • Six activities currently draw the ingredient, not the action — cut_wedges, zest, garnish, season, to_taste, simmer. That violates asset-spec's own rule. If your storyboard reproduces it, that is the placeholder misleading you.
  • A missing carried: true is the most common warning. Mark carried items distinctly on paper or the basket triples the chicken.
  • ordered: true on a single-tile page is meaningless — the one real nit found in recipe 1.
  • Digits are a live layer over static grammar. Never draw a quantity into the picture — scaling, unit toggles and live pricing all change it.
  • into: is data, not a caption. Settled 19 August: the frame shows where the food goes, so a caption only repeats the picture.
  • Waiting is never a page. Bolognese has 180 passive minutes and zero pages for them.
  • Never hand-type a measurable number. The ingredient count has been quoted as 177, 178 and 179 inside one week. matbakh.py status generates them; read the block at the top of the PM log, not any prose.
  • check counts the repo fixture as a recipe — a raw run reads 3 authored where two are real. status splits the two sources.
  • Clear the stale Excel lock file ~$matbakh-lexicon-review-annotated.xlsx in 03-catalogue/ref/ before any verdict lands in that workbook.
